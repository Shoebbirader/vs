 BROWSER DEVTOOLS (Testing)
───────────────────────────────────────────────────────────────────

Check Service Worker:
  • F12 → Application → Service Workers
  • Should show "sw.js" with "activated" status

Test Offline:
  • F12 → Network → Offline (checkbox)
  • Yellow "You're offline" banner appears
  • Try navigating around

View Cache:
  • F12 → Application → Cache Storage
  • See "vahansync-api", "vahansync-assets", etc.

───────────────────────────────────────────────────────────────────
 COMMON ISSUES & SOLUTIONS
───────────────────────────────────────────────────────────────────

Install Prompt Not Showing?
  → Must be HTTPS or localhost
  → Not in private/incognito mode
  → Not already installed

Offline Doesn't Work?
  → Clear cache: DevTools → Application → Storage → Clear All
  → Hard refresh: Ctrl+Shift+R
  → Check service worker is "activated"

App Crashes Offline?
  → Some API calls may fail (expected)
  → Check console for specific errors
  → Cached pages should still load

 USEFUL CONSOLE COMMANDS (Test in Browser)
───────────────────────────────────────────────────────────────────

Check Service Worker:
  navigator.serviceWorker.getRegistrations().then(r => console.log(r))

Check Cache Size:
  navigator.storage.estimate().then(e => console.log((e.usage/1024/1024).toFixed(2) + ' MB'))

Check Installation Status:
  window.matchMedia('(display-mode: standalone)').matches

Check Online Status:
  navigator.onLine
